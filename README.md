# Smart Knob
Rotary knob + round display smart home controller (ESP32-S3).

## Structure
- `hardware/` – KiCad project (open `smart-knob.kicad_pro`)
- `firmware/` – PlatformIO project
- `docs/` – datasheets and notes

## Build firmware
cd firmware && pio run -t upload
